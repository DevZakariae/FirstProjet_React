Projet pédagogique de réservation d'autocars au Maroc. Wijhati est le nom de ce projet de démonstration ; il n'est pas relié à un opérateur de transport officiel.

## Prérequis
- Node.js et npm installés
- Un terminal ouvert dans le dossier du projet

## Installation
```bash
npm install
npm start
```
L'application s'ouvre généralement sur http://localhost:3000.

## Fonctionnalités de la démo
- Recherche par ville de départ, destination, date et nombre de passagers
- Liste de départs de démonstration
- Sélection de sièges
- Récapitulatif de réservation et faux écran de confirmation
- Interface responsive ordinateur/mobile

## Important
Les horaires et prix sont fictifs. La confirmation n'est pas un billet officiel. Il n'y a ni paiement réel, ni compte utilisateur, ni connexion à une API de transport. Pour un service réel, il faudrait un backend, une base de données, des données de réservation autorisées et un prestataire de paiement.
